## 🚀 What I'm Building

### 🌱 STEMBridge

A student-led educational initiative providing free academic resources, particularly for Pakistani students following the FBISE curriculum in Grades 9–12.

Our mission is to make quality education more accessible, regardless of a student's financial circumstances.

**Explore the STEMBridge ecosystem:**

| Platform | Description |
|---|---|
| 📺 [STEMBridge YouTube](https://www.youtube.com/@STEMBridgeOfficial) | Free academic lessons, explanations and examination preparation |
| 📝 [STEMBridge Learning](https://stembridgelearning.blogspot.com/) | Educational articles, guides and learning resources |
| 🧮 [STEMBridge Stats](https://stembridgestats.netlify.app/) | Educational statistics and browser-based tools |
| 🛠️ [STEMBridge Tools](https://stembridgetools.netlify.app/) | Free online educational tools and calculators |

### 🗣️ STEMBridge Speaks

A free AI-powered conversational language-learning platform supporting **seven languages**.

Developed to help learners move beyond memorising vocabulary and grammar towards understanding natural conversations and communicating confidently.

🌐 **Website:** [stembridgespeaks.tech](https://stembridgespeaks.tech/)

## 💻 Selected Projects

### 🧠 BleedCheck CT

A research prototype using ResNet18 to investigate potential brain haemorrhage classification from head CT slices.

The project explores model generalisation and evaluates performance on an external data source.

- 💻 [GitHub Repository](https://github.com/aarishasifkhan/veritas-hackathon-2026)
- 🚀 [Live Demonstration](https://bleedcheck-ct.streamlit.app/)

*Research prototype — not a clinically validated diagnostic system.*
